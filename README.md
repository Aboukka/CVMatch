# CVMatch — Aperçu composant

Un aperçu local du composant `OffreClubProjetsPremium` est maintenant disponible via Vite.

## Lancer l'aperçu

```bash
npm install
npm run dev
```

Puis ouvrir l'URL affichée dans le terminal (par défaut `http://localhost:5173`).

## Build production

```bash
npm run build
```
